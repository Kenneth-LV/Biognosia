# Biognosia
Una plataforma para aprender sobre la biodiversidad y acercarte al mundo natural: explora una enciclopedia taxonómica, registra hallazgos en un cuaderno de campo e identifica organismos por fotografías con IA propia. Convierte cada encuentro con la naturaleza en una oportunidad para descubrir y comprender la vida, incluso sin internet 🌿🧬.
